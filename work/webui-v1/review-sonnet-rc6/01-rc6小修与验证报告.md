## 测试与两次变异确认

全套测试从最终 rc6 wheel 的独立离线安装运行，`TTO_WEB_TEST_INSTALLED=1`：**75 passed，8 个既有 aiohttp NotAppKeyWarning**。数量为 rc5 的 73 项加两个测试；三个 schema 反例并入原测试。无新增运行依赖、兜底分支或为测试增加的生产属性。

```sh
TTO_WEB_TEST_INSTALLED=1 PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 \
PYTHONPATH=/private/tmp/tto-rc6-test-deps \
/private/tmp/tto-web-rc6-final/current/env/bin/python \
-m pytest -p pytest_asyncio.plugin -q
```

测试依赖在只含 pytest/jsonschema 及其依赖的临时目录中提供；runtime-import-provenance.json 确认 tto_web/tto/tto_field、aiohttp、NumPy、SciPy、socketio、psutil 均来自 rc6 独立安装的 site-packages。没有靠源码路径覆盖已安装产品模块。测试依赖不是产品依赖，不进入 wheel/wheelhouse；独立审查环境需自备 pytest 8.3.5、pytest-asyncio 0.26.0、jsonschema 4.23.0 或兼容版本。

| 变异（仅临时安装副本） | 结果与失败原因 |
| --- | --- |
| 删除 `if t<=self.model_gap_t: return`（源码为两行） | **1 failed / exit 1**；新增屏障测试在历史不变断言失败，多出 `t=3000` 的有效 ModelRow。 |
| 记录 Tf 时将 o['Tf_C'] 替为 tj['value'] | **1 failed / exit 1**；新增真实后验测试在 `assert tf!=tj` 失败，二者均为 47.006802782297285。 |

原始输出分别在 `evidence/rc6/mutation-barrier.log`、`mutation-posterior.log`；`mutation-results.json` 记录精确替换、实际导入临时路径、前后哈希和退出码。正式源码/安装目录的 state.py 未被修改，副本用后清理。可用 `verify-targets.py` 搭配安装 Python 与测试依赖目录复现。
`schema-results.json` 单独列出三个旧接受/新拒绝的错误路径及三个正常示例名称。

验证环境记录：首次全套测试借用了开发环境 site-packages，75 项通过且运行依赖版本一致；随后为确保依赖来源也属于独立安装，改为只借用测试依赖并重跑上述最终验证。准备隔离目录时曾漏 pytest 的 py.py，导致测试启动前 ImportError，原始日志保留于 qa-setup-incomplete.log；补齐测试环境后重新完整通过。产品及最终 wheel 均未为此修改。

## 逐文件差异与开销

`02-rc5至rc6逐文件差异.md` 列出 8 个改动文件和 1 个新增测试 fixture；完整前后 SHA256 在 `rc5-to-rc6-file-diff.json`，文本差异在 `patches/rc5-to-rc6.patch`。
两个工具的变化严格等于把 rc5 版本字符串替为 rc6，不改变构建/回读逻辑。

wheel 内非 dist-info 文件共 68 个：64 个逐字节相同，4 个变化为 __init__.py（版本）、series.schema.json、model-history-contract.md、web-candidate-files.json。dist-info 中的版本目录、METADATA 与 RECORD 随版本/内容更新。
state.py、server.py、其它运行 Python、全部 vendor（含冻结观察器/model/spec）和三个静态资产均与 rc5 相同；没有重新构建前端。Sonnet 的 8 个前端源/配置文件与本轮开始时逐字节相同。

本轮没有新增缓存、线程、定时器、接口调用或计算；schema/合同仅为分发文件，未引入运行时校验路径。wheel 增加 305 字节。不宣称重新测过资源占用：rc5 短测、Sonnet 对整小时查询和密集缺口的警示继续有效。N305 的内存/CPU/长稳以及同时填满预测/事件缓存仍待现场验证。
