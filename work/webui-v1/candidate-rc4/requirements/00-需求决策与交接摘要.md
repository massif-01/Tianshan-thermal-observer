# 本轮冻结决定

1. 只做59009上的只读热观察Web UI；原TianshanOS继续控制。
2. 小指标条、温度/功率/PWM主趋势；A事件带/B折叠健康；C模型小节点、D成熟预测对照、E当前运行语义全部是V1。
3. 排除结构温度传感器、YET、摄像头、回放/录像/诊断操作页面；保留Ts但叫“模型内部慢态”，不叫结构测温。
4. 所有数值来自已拉取数据或明确的新版本只读计算。没有实时来源的任务状态、RPM有效性、概率和建议映射不猜。
5. 未来TJ用冻结G2-HOLD15/45/90，新增真实发布和成熟标签评分，独立于A类好成绩。默认45秒、同epoch目标以后≤2秒首个有效TJ。
6. 观察建议允许显示但不等于控制：真实provider优先；可验证已有曲线映射为后备新计算；无映射给原因。不得index×100、target_duty冒充G2建议、默认安全温限或曲线搜索。
7. 安装后Web服务启动和开机自启属于本轮目标；follow/observe必须有真实入口和单实例保护。本轮开发不实际部署N305。
8. 默认中文，单页锚点；不再生成一张图替代PRD或指令。本包不是另一次模型研究或现场执行授权。
9. 本包为新的“**TTO Web UI**”独立Codex对话使用。原模型、通讯、CPU补测工作不重开；若需配合仅取得已接受源/发布接口。
