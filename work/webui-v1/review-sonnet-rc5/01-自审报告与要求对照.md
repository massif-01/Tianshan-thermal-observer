## 4. 测试必要性与覆盖

最终安装环境 **73 passed / 8 既有 aiohttp NotAppKeyWarning，用时 19.39s**。最终精简交付目录也执行同套测试，73 passed，用时 19.47s，确认工具筛选未破坏复现路径。数量变化为 rc4 的 72 项删除 1 项重复身份单测、增加 2 个构建保护参数用例。23 项模型历史/合同用例保留，同采样、九类资格反例、重复 TJ、迟到屏障、断源、冻结身份拒绝、极值/短段/有界性、实际发布/HTTP、无源/示例校验均有明确业务判据。

新增构建测试对应已复现的覆盖缺陷，未镜像模型计算。合同四个反例扩展既有测试，没有为凑数量拆成四项。合法模型热切换的全局 monkeypatch 部分已删除；生产不允许热加载另一冻结模型，不用伪造合同获得该分支的通过成绩。

一次审计比较以固定 seed=514，在 300 次合成来源状态转换中进行 900 次公开序列查询，rc4 与最终安装 rc5 结果全部一致；同时逐行核对联合缓存，覆盖不同 phase、间隔、到期、重复与 publication_gap。它用于验证精简没有改变历史行为，是可复现审计证据，不是生产特判或新增常驻测试逻辑。

真实 Chrome 使用最终安装的 app/static/API；最小接入页确认缺口前后 4→8 个独立曲线段、静默末值 null、新样本恢复、同 run 从 epoch 1→2 后忽略带 777.123 哨兵的旧历史响应。原 D 区 epoch 2→3 时也清空旧评分，并在旧响应实际返回后保持清空。包含 DOM/具名表格/可访问性树和截图。本轮未复跑未改变的旧版本多轮长资源/网络实验，不把历史成绩称作新结果。

## 5. 开销与保护范围

最终 rc5 wheel 本机受控短测：120.63s，Web 单核等效平均 CPU **3.075%**、RSS 峰值 **163.875 MiB**，满足 5%/192 MiB 门槛。18002 行共享缓存新增存活分配 **8.086 MiB**，满足 16 MiB；查询后约 8.10 MiB，清空后约 20 KiB。共同请求最大约 17.18ms、227889 字节。

条件为一个 Chrome 页面、独立合成 1Hz 发布进程、既有数值及联合历史预填至 18002 行，候选每 2 秒共同请求一次；源观察器 CPU/RSS 单列，浏览器只记录 JS 堆，不计入 Web 过程指标。未同时填满全部预测/事件缓存，120s 不能证明长期或 N305 稳定；不把 rc4/rc3 数字拼成 rc5 长跑，也不解释两次 RSS 差异为优化收益。

frontend/vendor/原始 requirements 共 72 项核对无变化，冻结 model/spec hash 保持。静态资源与封存 rc3 逐字节一致，没有构建或改动 Sonnet 前端。rc4 wheel/ZIP 原 hash 保留，未覆盖旧交付。
