## 请重点检查

- 模型值是否来自同一新 TJ 的校正后状态，是否有用未来预测、缓存 TJ 或后续 tick 状态回填旧时刻。
- phase/TTL/断源/发布缺口与迟到包屏障是否正确；历史好点保留与当前撤值是否分开。
- 联合抽样是否真正同索引，并保留残差/两个状态差值的极值、全部断点和短有效段。
- 完整身份和请求代次是否足够支撑你的前端；同 run 换 epoch、暂停/恢复、旧请求返回时是否需要改进接入。
- schema 是否准确描述真实响应；Tf/Ts/E 是估计，TJ−Tf 是校正后残差，负差值不能截零；不能宣称实测结构温度、室温、热量占比或独立预测准确率。
- 新增代码、测试及构建保护是否必要，是否出现只为测试通过的状态、fallback 或全局合同修改。
- 新候选的源码、wheel、版本、静态资产和证据是否对应同一身份；资源证据是否被越界解释。

请输出“可接入 / 需修正后接入 / 阻塞”，附具体文件、触发步骤、影响及最小修正；区分阻塞缺陷与非阻塞建议。若你的交接原件与本包摘要或批准方案有关键差异，请明确指出。
