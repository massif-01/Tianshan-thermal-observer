# TTO Web UI：验收与针对性测试清单

本清单以用户价值和真实调用链为单位，不要求重跑整个TTO历史测试，不修改模型成绩。UI V1仍是新增软件候选，验收通过不代表热预测普遍准确或风扇控制有效。

## 一、产品与交互（U）

| ID | 必测事项 | 通过标准 |
|---|---|---|
| U01 | 1440/1920/窄屏布局 | 小指标、三个主图默认展开；C/D/E始终存在；不恢复图片/录像/诊断页 |
| U02 | 卡片与单位 | 温度/W/%/RPM/MB各自正确；卡片不撑成大仪表盘；可读原精度 |
| U03 | 时间联动 | 三图与事件带同范围/光标；tooltip列出各系列真实样本时间，不假同步 |
| U04 | 暂停/全屏/图例 | 仅改变显示；多浏览器互不停止观察，刷新不重新初始化模型 |
| U05 | 节点关系与动效 | 仅实际G2依赖；TJ校正不是热功率；无效边不流动，减少动效设置有效 |
| U06 | C/D/E缺项分支 | 无模型/初始化/降级/无任务/无建议映射都有准确文案，不缩减模块或套demo |
| U07 | 数据源/事件折叠 | 默认收起；重大明确异常在顶栏可见；恢复/重复计数不刷屏 |
| U08 | 所有已接字段 | 分类抽屉覆盖allowlist，逐核CPU/内存/其他rail可查，不泄漏raw binding |

## 二、数据语义与模型（D）

| ID | 必测事项 | 通过标准 |
|---|---|---|
| D01 | mW到W及GPU年龄 | current/average不混，GPU独立有效期不被WS新消息延长；不合成总功耗 |
| D02 | 有效零/缺失/失效 | 普通零保留；missing不补0；新invalid撤旧valid，不回退到旧帧冒充当前 |
| D03 | RPM反例 | rpm=0+running=true无测速证据显示未确认；不写停转、不按PWM算RPM |
| D04 | 同值新采样与缓存重复 | 新ID相同值保留；旧缓存重复不续TTL/动画新样本/累计确认 |
| D05 | 断连/恢复/epoch | 页面可继续开着但撤旧当前值；新合法源恢复；跨run不拼曲线/误差 |
| D06 | 模型身份与时钟 | 使用真实外层clock；内部offline字面量不被当live；单实例冻结θ相同 |
| D07 | G2-HOLD数值与因果 | 小样本对照既有传播；未来功率/温度扰动不改变之前已发预测；15/45/90均有实算 |
| D08 | 成熟标签与正负误差 | 第一个同epoch目标以后≤2s有效TJ；待到期/缺标签单列；error=predicted-actual |
| D09 | 指标分母与切换 | horizon/model/scenario/run不混排；MAE/P95/max低估/count来自同集合，不把tracking当准确率 |
| D10 | 发布延迟/历史回放 | origin/issued/target不同概念；晚于target不算未来预测；回放不可显示LIVE |
| D11 | 建议provider真实范围 | valid provider或匹配曲线才给数值；缺映射/域外/保护未知null原因；target_duty独立 |
| D12 | 平稳需求/置信度 | index非PWM；Ts非结构测温；E非室温；未校准cov不冒称95%/0–1信心 |
| D13 | 工作语义 | 无runner不猜空载/并发；客户端DONE不等GPU停止；RAM不推模型驻留 |

## 三、服务/集成/安全（S）

| ID | 必测事项 | 通过标准 |
|---|---|---|
| S01 | 实际端到端 | 同一真实本地producer→quality/observer→API→SSE→浏览器链，来源一致 |
| S02 | follow单实例 | 多浏览器0新增设备轮询；Web启停不结束外部采集或请求 |
| S03 | observe与互斥 | 获共享锁后唯一collector/observer，0Requester；冲突不启动第二实例、不kill别人的进程 |
| S04 | 超时与背压 | 慢客户端/断开只损失显示侧，collector不等待浏览器；队列有上限，超界resync |
| S05 | 安装与服务 | 临时prefix实际加载新文件、静态资源完整；unit语法/启动候选验证；59009冲突明确报错，不杀占用程序 |
| S06 | 默认只读/访问 | 本机/LAN显式配置；无业务写API；拒绝跨源/任意proxy/秘密泄漏，源文本不执行脚本 |
| S07 | 常驻资源与磁盘 | 使用真实计量列附加CPU/RSS/流量；有限缓存/日志只清Web目录，超过预算不改源频率 |
| S08 | SSE恢复与质量过期 | Last-Event-ID可续或resync；心跳不续源样本；无新消息也按期限撤值 |
| S09 | 时钟/源码差异 | 墙钟跳变不破坏单调时长；未知域不乱配；最新候选有变更如实写，不改identity清单掩盖 |
| S10 | 无现场授权 | 开发日志中无真实设备调用、无推理POST、无N305安装/上游重启，文档实际可运行但未越界执行 |

## 四、阶段性放行

- **开发交付可接受：**真实代码/安装候选、核心U/D/S测试及明示未执行项；建议provider缺合法曲线可准确不可用，不为补数字临时创造控制算法。
- **正式部署可安排：**独立审查通过后，用户批准N305安装/启动只读服务与数据配置；不自动附带推理/仪表补测。
- **实际能力接受：**现场能看到数据、单实例、延迟/资源/失效正确；预测有误差是模型研究事实，不以UI“图贴得好看”作验收。

新功能没有实际测试不能宣称全部通过；测试数量按实际运行记，不把此处条目数当完成数。
