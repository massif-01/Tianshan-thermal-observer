# 依据、读取范围与不可继承的假设

本PRD据用户在当前对话的确定需求、所附报告和指定归档编制，未访问设备，未复跑所有科学实验，未修改GitHub。详细字段核对与归档SHA见数据核对摘要。

## 直接依据

- 《TTO-现场执行入口与诊断候选-收尾报告.md》：唯一collector/quality/observer/Requester关系、实际现场信封与时钟、来源/保护分层。资料虽含历史许可，不能当Web UI开发期设备许可。
- 《TTO-closeout.1-首次只读诊断与停止时刻修订报告.md》：N305/独立prefix、原1s/5s轮询和2.5s fan TTL、关闭后状态撤销；closeout.2与原模型分别保留身份。
- 《TTO-CPU旁录与针对性补测-运行准备报告.md》：cpu.1候选、真实1秒CPU/NVML语义、200ms能力尚待现场，不允许UI偷偷启动旁录。
- 《TTO-CPU增量活动信息-离线分析与冻结方案.md》：CPU候选未胜过HOLD，活动参数不能自动启用；当前Tf锚定TJ、Ts/E和θ语义；15/45/90对照；需求指数未映射PWM。
- 《TTO-快慢热状态与平稳散热需求-研究报告.md》：增量参考/塑形是研究指数，不是百分比建议或真实热量；快风险独立。
- 《TTO-冻结模型与CPU先导补测-GPT6Pro复审交接包.zip》：读取同run原observations与states实际字段，核到RPM全0+running真，没有测速valid字段；这些历史事实不代表今天每台设备都如此。
- 《TTO-CPU旁录与针对性补测-运行准备证据包.zip》：读取platform_engine/quality、projection、observer、runtime及冻结模型/spec，作为字段映射参考，不代替Codex最新本地源码基线。

## 公共技术参考（2026-10-20查阅，不等于目标机版本）

- NVIDIA tegrastats：https://docs.nvidia.com/jetson/archives/r36.5/DeveloperGuide/AT/JetsonLinuxDevelopmentTools/TegrastatsUtility.html
  用于温区/CPU/内存及rail单位语义，不假定Thor GPU一定来自tegrastats；本项目Thor既有NVML单独读取。
- MDN SSE：https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events/Using_server-sent_events
  id/retry/事件重连用于只读Web流；不是源测量采样时间。
- aiohttp：https://docs.aiohttp.org/en/stable/web_advanced.html
  HTTP静态资源、异步服务与生命周期；尽量沿用本项目已锁定版本，不以文档最新版本升级生产。
- systemd：https://www.freedesktop.org/software/systemd/man/257/systemd.service.html
  自动启动/Restart=on-failure为服务候选设计；要在目标可用版本核验，未在此处安装。
