# 05接口实际映射｜TTO-OBSERVE-v1

本候选没有第二套轮询/质量引擎。native/里原始observations先flush，再由同一native engine已经处理的结果供I-02与SavedStream消费。独立有界模型worker只读该快照；队列64、迟到0.25s、异常和丢帧有事件，不静默用旧值。全局native flock仍覆盖唯一采集，不删除或绕过。旧execute的formal、控制安全与现场许可不放宽。

|共同对象|实际位置/语义|
|---|---|
|device/config/host/session|registration与launch；native-binding关联唯一native UUID；每台各自进程和状态|
|软件/模型/spec|65项candidate-files；launch版本；run/thread-policy；g2_model/frozen-model-manifest（G2-FROZEN-RM01-v1）|
|源/单位|native manifest单位和原payload；TJ°C、原rail mW→模型独立rail W、successful PWM逻辑百分比；不求和、不代替RPM|
|原始CPU/GPU/memory/gain/保护|原WS/HTTP payload原样在native observations；不因暂停200ms CPU旁录删除普通遥测。原ref/seq/source age/window/unknown都保留|
|字段当前资格|observations的measurement/communication/raw_quality，以及原native事件；明确失效不回找旧valid，不填零、不续TTL|
|模型|states.state保留冻结科学结果/原clock文字；states.model为同一observer字段便捷别名；Tf/Ts/E及原不确定性/假设保留。Ts不是实测，E不是室温|
|旧消费封套|保留TTO-FIELD-CONSUMABLE-STATE-v1的state、native_run_id、expected_identity、process_clock_domain、clock、communication；增加observe_contract与独立生命周期字段。UI未做本轮联机验收，不宣称前端已接通|
|真正发布时间|predictions.issued_at.mono_s/utc/domain；实际计算完成后统一生成9条的发布时刻；computation_id/calculation_started_at仅是计算草稿，不冒充已发布|
|目标与截止|measurement_ref/measurement_received_mono_s来自原accepted TJ；target=原receive+h，h=15/45/90，原observed_through和source_epoch；有效提前量=target-issued，过目标null|
|方法与条件|G2-HOLD/B0/B1，调用模型线唯一Predictor；condition/assumptions及state_used明确两rail和PWM常持。B1只用过去TJ，不使用未来请求计划|
|发布节奏|每个合格原TJ判一次，5s发布stride沿现有特征合同；不是每0.1s重复整份gate。全部有效TJ分母和计划发布起点分母分开|
|成熟标签|scores：同一run/epoch/domain，目标之后最早合格TJ，最多+2s；没有插值，不把尚未成熟/缺答案填零|
|误差|prediction−actual，低估=max(actual−prediction,0)；最终summary有MAE/bias/P95绝对/P95和最大低估；P95=(n−1)*.95线性插值|
|比较与覆盖|per_method保留全量；same_set_G2_B0只在相同起点/答案双方都有值时比较。counts中valid_predictions/issued与scheduled_origin_denominator构成预测覆盖；scored n/valid_predictions为标签覆盖；另报all_native_valid_TJ_denominator|
|业务事件|可选registration.workload_event_source(path/session_id/clock_domain/complete_from_session_start)，同进程每秒有界读取≤64KiB已有日志并调用04原样Adapter；轮转/缺失/坏行→unknown。source无心跳时只表示事件发生时的在途，不是当前整机请求数|
|实验与控制|observe start_allowed=false、experiment_authorization=false、control_permission=false；只读窗口许可在launch独立保管，不让有限模型值代替业务负载或真实控制许可|

模型线已确认发布层映射：纯API使用同一状态和计算起点，发布器在计算结束后重新标真实issued_at并重新检查lead/late；保留计算ID，正式prediction_id另建。模型数学和值不依赖未来输入；不得把旧草稿时间直接当发布，晚于目标必须null。A类未来真实功率诊断仍仅离线，不进入live ledger。

`publication_mode=live`仅指本程序确在当时发布；测试用loopback身份/source_scope/self_owned_loopback与native.simulated另标，不能当现场成绩。历史加速重放一律replay：分析单调时刻和真实墙钟另存，不与live新口径或旧历史排名混合。

原fan TTL2.5s、temp TTL7.5s和源新鲜度不改。原spec短缺口允许条件传播、长期缺失禁用后原规则冷启动恢复；不把unknown改tracking。I-02原样保留断连即撤销、重连旧缓存不复活。observe只把WS总尝试改为有界的原预算burst与原max backoff后再试，仍受总窗口/资源约束；不以WS断开结束无关HTTP/raw。非observe沿旧总尝试预算。

原始队列丢失是保真阻断；模型队列丢失是模型覆盖缺口。模型投影软件异常不重建I-02来复活缓存：该会话停模型消费，原生和同一I-02继续，字段质量仍能追溯。磁盘/IO错误停止自己的程序，未索引状态不得叫归档成功。
