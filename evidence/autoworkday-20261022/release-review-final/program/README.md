# 自动工作日总控 v1

当前仅离线准备，未授权现场。observe.2 wheel和冻结G2不变。该新profile前向替代旧04“先停observe再execute”的接续条款；旧execute不改，本程序绝不调用它。

目标拓扑：同一观察主机，一个总控进程（唯一请求执行器与监督），一个原observe.2子进程（唯一collector/热观察器）；模型服务独立既有。由本地单调时钟独立运行，不依赖聊天、浏览器或交互终端。现场以用户服务Restart=no托管。

原读许可仍只读；另一个负载许可精确绑定计划、请求配置、设备/config/session、程序和观察身份。默认前7200秒背景；单路、≤600提交/≤18000秒客户端在途；末1800秒无新请求；窗口最多86400秒含收尾归档。源类型为真实设备+自动构造工作负载；未来排程绝不注入G2。

准入映射唯一observe现有status.latest_state：保留原raw_valid/绝对有效期、I-02、AUTO/保护/绑定与5秒确认。新profile明确不以旧YET或model.available/预测输赢作为负载gate；有限模型值不产生许可。新测量门控不复制采集/引擎，也不修改2.5s/7.5s TTL。heartbeat最多3秒是1Hz进程状态新鲜性检查，不是延长字段TTL。不合格暂停，连续60秒停止自动负载；明确保护/身份变化/观察退出停止后续。观察可继续，负载未完成如实说明。

资源预登记：观察器仍原8%/128MiB；驱动器rolling10s CPU>5%持续30s或RSS>64MiB停止驱动；二者同机合计（不是整机全部业务进程）rolling10s CPU>8%持续30s或RSS>192MiB停止新增负载，保留观察自身边界。参考目标合计平均5%。1Hz保存独立与合计资源，不把独立执行器开销视为零。驱动证据最多256MiB（含响应），最少剩余1GiB；不删除旧文件，过预算停请求。24h内预留120秒结束/归档，观察进程运行至窗口-120s；归档最长60s且受同一最终截止，超时保留部分和失败，不延长或伪称完成。

其他负载只能登记批准的使用窗口/未知，不通过本执行器inflight=0猜整机无人工作。正式开始前唯一Requester可做一次已批准的驻留/空闲只读核对，绝不切模型/重启服务。用户可pause/resume（原窗口内）或stop；stop立即禁止后续请求，已提交按原30秒预算有界自然收尾，未知完成不可恢复。用户STOP结束自己的整窗，保护/准入失败仅结束负载，原始观察可继续。

没有有效TJ/两rail时只能称通信/记录诊断，不能称热模型试跑。自动检查和归档均受本地单调总窗及许可UTC截止中更早者约束，许可失效不延长。
