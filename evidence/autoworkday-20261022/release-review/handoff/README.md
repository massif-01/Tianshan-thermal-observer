# TTO：自动模拟工作日，而不是要求用户连续工作

版本：TTO-AUTOWORKDAY-PLAN-v1.0；日期：2026-10-22。
性质：新的产品安排与有限实施指令；不是已实现软件、代码复审结论或现场启动许可。

## 本次决定

24小时是软件观察的最长经过时间，不是人要工作24小时，也不是GPU要满载24小时。前2小时同样不要求用户坐在旁边。本次改为：由本地有界程序自动执行预先登记的请求节奏，包含大量空闲与一段长休息；用户只需确认设备/窗口/范围和一次开始。

保留已接受的observe.2、G2、原参数/成绩及采集规则。暂停的CPU逐核/200ms/CPU12不恢复。新增范围仅为自动任务驱动、与唯一观察器的连接、必要监督/停止和事件归档。
