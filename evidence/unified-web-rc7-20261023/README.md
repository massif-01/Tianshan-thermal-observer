## 改动与边界

- 浏览器按 `forecast.status`、`remaining_valid_ms` 和 `latest_prediction_ids` 展示，删除独立 15 秒筛选规则。不再选中后台未授权的其他 pending 预测，不计算预测或评分。保留固定目标时刻和发出时间说明；目标/签发 UTC 取后台原记录。
- 预测期限与模型期限分别到期；当前参考、节点、流动连线及建议相应撤回。历史记录仍由后台账本接口提供。
- 本轮发现并修复 Web 关闭缺陷：有 SSE 订阅时，旧关闭入口未结束请求，aiohttp 两段等待合计约 10 秒。现在在唯一 shutdown 入口结束显示订阅；原 CLI 测试主动保持订阅，保留原 10 秒上限。握手阶段也纳入原 try/finally，失败不泄漏四客户端预算；强化原服务测试。
- 安装包包含后端 `0.2.4+observe.5` 和 Web `1.0.0rc7`，新 prefix 内各自独立 venv，固定 `follow`、`--service none --access local`；安装不启动服务或来源。全新输出保护、旧依赖身份、wheel 实际文件及安装材料 SHA 均验证。
- 未改变 observe.5 后端运行源码/模型/规格/采集步长/评分规则，后端 wheel SHA 与 PR #20 相同。这里的“未改变”只指相对已接受的 observe.5；相对 N305 旧 observe.2 软件身份已经改变。
