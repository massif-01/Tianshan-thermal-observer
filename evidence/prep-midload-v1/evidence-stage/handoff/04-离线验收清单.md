# 本轮离线验收清单

**TTO-PREP-MIDLOAD-v1.0**。下面是软件验收，当前全部为待执行。用例编号帮助对应证据，不是要求造独立框架或达到某个测试数量。

| 编号 | 检查 | 必须观察到的结果 |
|---|---|---|
| P01 | 工作树与旧研究 | 起点SHA/差异保留；研究原件、spec、参数、旧报告和测试账本不变；不reset/clean |
| P02 | 归档入口 | 从README可定位研究代码、冻结模型和证据SHA；未强制把大ZIP放Git；没有把研究模型标deployable |
| C01 | 原调度反例 | 实际生产轮询在可控temp延迟下展示共享等待/完成后等周期的行为；记录调用时间而非仅比较字符串 |
| C02 | 修改后正常/慢temp | 同配置、同响应条件下fan无需等temp循环完成；真实返回间隔和缺口改善可量化，未改TTL |
| C03 | 频率与并发 | fan/temp各最多1个在途、合计最多2个；相邻发起不短于配置周期；错过周期只计skip，不追赶突发 |
| C04 | fan自身慢或超时 | 缺口仍真实出现且记录原因，不伪造成功值；temp仍可独立工作；失败不无限重试 |
| C05 | 停止与原网络合同 | Ctrl-C/时长到期/401-403取消和资源关闭；原只读URL/TLS/不跳转/响应大小等关联回归仍有效 |
| C06 | 时间与资源 | 计划、发起、接收时间分别记录；不让来源年龄被重打戳；不产生第二个诊断轮询器；开销按实际环境报告 |
| E01 | 旧结果 | 旧严格资格可复核，保留L12/S27和连续短问答6个45秒答案的来源；旧参数/原日志SHA不变 |
| E02 | 未来仅fan空隙 | A不能跨越；B已发值不变，有同源真实TJ答案则记录误差并标辅助缺口，不谎称正常 |
| E03 | 未来仅功率空隙 | 与E02同样区分输入响应和温度答案；不补未来功率、不修改源质量 |
| E04 | 起点缺PWM/历史不足 | G2/R_IO不起预测；TJ方法按自身输入另列；不能以后补回当时缺失输入 |
| E05 | 明确失温/保护/配置变更 | 排除正常集合，保留异常后果及原始引用；源身份冲突/隔离时不恢复非法答案 |
| E06 | 各时距与覆盖 | 有45秒没有90秒仍可评分45秒；没有答案不填0；分母、子集、共同集合ID和排除理由完整 |
| E07 | 因果与保存事实 | 改未来TJ/任务结束不改变B已发值；A可受未来输入影响；不补发原来没发的预测；新旧表分开 |
| E08 | 图表口径 | JSON/Markdown/图共同结果；事件峰值与模型比较使用同一有效时间集合；温升面积不是热量 |
| W01 | 默认离线 | 带真实形式但不可访问的URL执行help/plan/dry-run也零外连；不读取或打印凭据内容 |
| W02 | 整轮排程 | 注入时钟快进600/20/420/60/600/180/600计划；各块单路、截止后不发新请求；实际结束后再计回落 |
| W03 | 自然drain/未知超时 | 请求跨发起窗口只等预算内自然结束；timeout标未知、停止后续，不假装服务器已停止，不杀服务 |
| W04 | 硬截止与用户停止 | 总45分钟包含检查/等待/收尾；Ctrl-C或采集失败停止新负载；不自动延时重测；只清理自己的任务 |
| W05 | 健康准入 | 用同一采集流检查近期60秒完整输入及当前AUTO状态；无条件时只留数据，不新增请求器探测或忽略缺口 |
| W06 | 环境和打点 | 计划与实际时间分开；null室温不变25°C；现场时刻/写入时刻明确；未来结束计划不进入预测器 |
| W07 | 真实协议集成 | 仅自建loopback完成SSE/普通请求、首内容、DONE、早结束、EOF异常与响应超时，不冒充实机验证 |
| D01 | 新安装候选 | 若运行包变更，新版本+wheel/源码/实际导入一致；不沿用旧SHA；非editable临时安装通过离线入口 |
| D02 | 操作卡 | 真实入口、路径、停止、输出及回退步骤齐全；新命令已实现并测试，不交用户虚构命令 |
| D03 | 最终证据 | patch范围清楚、根因/修改前后日志保留、全包SHA可验证、现场未执行状态准确、没有自动Git写入 |

## 必须保留的反例语义

一个fan快照在t后失去可见性，不等于真实PWM=0，也不等于TJ失效；而“现在无法确认”同样不能写成“全程AUTO正常”。新B分层是问题定义修正，不是对未知事实进行插补。

## 不做哪些测试

不跑真实45分钟负载；不故意制造ESP32失温；不刷固件；不跑全设备认证；不追加模型结构/大量参数搜索；不因为现场尚未跑就谎称软件失败。保留原项目常规关联测试，未执行部分明确注明。
