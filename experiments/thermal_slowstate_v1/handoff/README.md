# 交给哪个Codex对话？

**交给负责“灰箱辨识和对照实验”的对话。测试对话本轮不动。**

本包是在第二轮研究已经完成后，依据用户进一步明确的产品目标安排的一次离线研究任务。它不是新固件、安装包，也不是要求立刻重新测试。

## 这次只回答三件事

1. 原G2真正的潜在慢热状态是什么样，是否稳定、是否有可用信息？
2. 它与普通因果低通/无慢记忆参照相比，是否能更好解释后续温度？
3. 在不发PWM的情况下，用它生成的普通散热需求能否表现出合理平稳性；哪些需求只是控制塑形造成的？

产品目标是合理利用热惯性、减少无意义调速，但真实TJ风险仍需被看见。模型把TJ算偏不能自动解释成“算准了铝体”；控制延时与模型迟滞分别处理。

## 阅读与执行

`01-实施方案.md`是规范正文；`02-给Codex的指令.txt`可直接作为进入文本；`templates/slowstate-spec.json`为机器可读起点。

`references/`包含旧成果报告、独立核对和这次决策记录。

`inputs/r2-results-original.zip`包含第二轮所有已交付实现、模型与逐点结果。
`inputs/r2-prerequisites-original.zip`为其bootstrap所需的完整原前置交接；数据已齐，不需用户再次找旧附件。

历史前置包中的执行任务已经完成，**只使用其材料，不再执行其中的重训、测试或发布任务**。不得运行`research.py refit/all`或`rerun.py`去重新训练42次。

可在一次性工作目录解开两个input ZIP，用原`bootstrap.py --handoff <前置包目录>`构造离线缓存。此步会写副本缓存，不修改任何原ZIP；原SHA先核验。建模对话已有正确缓存即可复用。

先运行：

```sh
python scripts/verify_package.py
```

该命令只核对本包文件与两个ZIP的CRC，不访问设备，不运行模型或优化器。

本轮新增研究成果写新目录；无须部署、推送或改主线。研究模型仍为deployable=false。
