# 离线验收：只验证本轮真实新增风险

本轮不实测，不拟合模型。下面是行为类别，不要求为每个勾选另造框架。

| 编号 | 验收行为 |
|---|---|
| T01 | help/plan/import/compare默认不联网、不访问相机/设备、不读鉴权文件；watch仅读指定本地日志。 |
| T02 | 同一固定事件序列产生相同提醒；事件迟到/重复、用户漏测、程序从旧日志中启动不产生追赶提醒风暴；模型预测变动不影响提醒。 |
| T03 | 提示时间≠测量时间≠写入时间；迟录/未知时间/有时区及无时区、两个时钟域、一个偏移锚点、区间跨缺口分别按合同处理。 |
| T04 | 同测点/会话/统计量对应正确；背板/鳍片/空气不可静默合并；缺温度保留null；摄氏/华氏明确换算；NaN/Infinity不作为正常读数。 |
| T05 | 录入更正可追溯；重复导入不膨胀样本；原图SHA、原始文件、旧run和模型字节不变。 |
| T06 | 无品牌样例时通用数值导入和人工路径仍可用；普通伪彩图片没有数字不能按颜色/OCR编造温度；图像元数据时间与mtime区分。 |
| T07 | 外部温度改变不改变冻结G2/Ts/LP原输出，不进入拟合或B预测输入；空测温也能生成说明。 |
| T08 | 对齐不跨TTL/源质量缺口；区间时间不挑最有利模型点；原温度及模型断线保留，不把插值当观测。 |
| T09 | 单个预登记参考而非每阶段重新归零；原温度、时间不确定性、参与比较点数与未配对原因都可回查；不声称稀疏点测到了完整峰值。 |
| T10 | 合成端到端输入→提醒/人工补记→导入→对齐→中文报告一次完成；模型/单位/来源/旗标与JSON、图表、文字一致。 |
| T11 | 原跨平台Tf重算采用已约定1e-10数值容差；参数与原件SHA仍严格。修此断言不重训、不重跑整套模型搜索。 |
| D01 | Issue #1最新正文/评论已回读并查重；旧历史保留；当前状态与M0—M5勾选不冒报在线学习/控制/跨硬件完成。 |
| D02 | PR #2状态用真实读回；新文档PR只含文档，未自动合并；main/本地0.2.4实测/研究成果身份不混同；所有回链可访问且不含凭据。 |
| D03 | 软件只本地patch；文档远程失败不伪报，留待发布内容；没有上传真实日志或任意旁支文件。 |

交付报告列实际环境、真正执行数量、没执行的事项。只重跑直接受影响的既有研究测试，不做全仓防御矩阵。
