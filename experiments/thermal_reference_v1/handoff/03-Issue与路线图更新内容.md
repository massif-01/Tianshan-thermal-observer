## 2. 对是否偏离路线的裁定

**主研究没有偏离：**原M2正是低阶灰箱、模型生成及与简单方法比较，M3包含状态估计与后续参数学习。实际G1/G2辨识、三轮真实数据、快慢状态对照是推进这些目标。

**需要纠偏的倾向：**不能把45秒单点误差当全部产品目标；不能把平滑的需求指数当实际控制收益；不能把Ts必须等于某块可测表面的绝对温度，或额外传感器可用，当作整个TTO继续工作的硬门槛；不能一直补同类测试而无限搁置在线校准。

本次校正没有取消真实TJ预测、可信数据、慢态物理解释或未来控制验证，只是把它们分成各自的证据任务。

### 3.4 补充四条当前原则

1. 产品希望短脉冲不直接复制为风扇忽高忽低，连续工作形成适度平台，真实风险优先；平稳不等于固定不动，也不等于始终最低风量。
2. TJ、Tf、潜在Ts、局部表面参照、出风空气温度、需求指数、实际PWM分别命名。外部热像只测能看到的表面，不作为整个热容器真值。
3. 外部测温可先采用少量人工/热像点，保留真实拍摄时间和不确定性；不作为全局必需输入，未测不报通过。物理解释和最终控制收益需要对应的额外证据，不能被软件通过代替。
4. 保留Ridge与简单滤波。自然推理中两rail共同活动是正常使用方式，不因共线否定组合预测价值；独立热源归因和域外迁移另验证。
