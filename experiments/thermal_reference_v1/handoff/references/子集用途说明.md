# 原样参考子集的用途

slowstate-snapshot/是已交研究证据包的一部分：冻结模型、当前状态/滤波代码及少量元数据。source-index.json列出成员原路径与哈希，不能据这个子集宣称重新执行了全部研究。

trajectory-format-samples/为原派生文件开头若干行，仅帮助对齐实际字段，三个温度轨迹的完整重放请复用建模工作区已有原件。样本不是新实测、更不是独立测温数据。

runner-event-reference/仅显示已核验0.2.4工具的本地事件结构。不要覆盖现有runner或运行这些只读副本。本轮工具仅读实际runner发出的事件，不控制其排程。

新的外部测温数值当前一个也没有；templates里null就是未测，不用模型输出冒充传感器读数。
