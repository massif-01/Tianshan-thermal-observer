# 连续接触测温：一页操作卡（ADD1）

**软件已完成通用离线验证；真实YET-610L CSV映射待1～2分钟样例；现场测温未执行。现在仅复审和离线演示，不启动仪表、设备或新负载。**

已购买YET-610L、K型探头和耐温聚酰亚胺胶带。未来由用户将感温端固定在同一局部散热表面；记录位置、实际表面情况和固定方式。背板用另一测点/会话。无需再选购器材或以安装照作为软件开工条件。接触式不填红外发射率、反射温度、ROI；局部读数不等于空气、整块均温或直接测得Ts。

**现在可运行的单一离线入口（在本研究目录）：**

```sh
python3 ref.py plan
python3 run_offline.py --output /private/tmp/tto-reference-demo-NEW
```

输出含连续CSV合成、人工/红外备用、零测温三类报告。合成CSV不是YET真实格式，也不是现场读数。

**下一次另获现场授权后的四项操作：**

1. **开始独立记录。** 计划1秒保存一次，确认仪表实际设置；TTO保持原AUTO、曲线、gain、保护与既有采样。用户操作仪表，不连接N305、不运行USB/串口驱动。工具不启动负载。
2. **记录开始锚点。** 开始附近独立核对仪表时钟与带时区的主机UTC时间；只有相对秒/序号时，记录“仪表第0秒/首序号对应的开始时间区间”和记录间隔设置依据。保留按下开始前/后的主机时间作为不确定区间；不将按键瞬间冒充第一采样时刻。能拍下时钟则关联照片，不能拍也可明确写下核对经过和误差。开始时间与仪表采样、导出、导入分开。
3. **结束附近再次核对时钟，然后结束记录。** 保存结束锚点及误差，用独立首末锚点检查漂移；不看两条温度曲线重合程度调时。漏点不延长、不重跑。实际CSV核对中位/最小/最大间隔、倒序/同时间和缺点，1秒采样不证明探头响应已标定。
4. **探头移动、重贴或松脱时另记事件并换测量会话。** 原会话后续值保留，暂停其独立对照资格；不静默接着算同一表面。只记录事件，不由本工具改变任务。条件不安全时停止测量并由现场人员处理，不触碰旋转部件或遮挡风道。

**结束后一次交回：** 原始CSV、仪器记录间隔依据、开始/结束钟点及误差、通道/测点/固定表面说明、异常/移动记录。无需十几次抄读数，也无需逐点发聊天。实际样例到货后仅补必要映射与回归。

**导入真实样例前**复制`templates/contact-session.example.json`和`templates/numeric-export-mapping.example.json`，填真实run ID、CSV列名/单位/通道→会话/测点映射及独立时钟锚点；示例占位符不是已知YET列名。新run环境温度另记，不能复制旧M的24°C。仅相对秒用`relative_seconds`，序号用`sample_index`并明确`index_origin`、`sample_interval_s`和依据；绝对采样时间用`timestamp`。宽表每次选择一个真实温度列并指定通道，分通道导入。一个会话至多预登记一个背景记录ID；未定可留null，不事后挑最贴合的参考。

```sh
python3 ref.py init-session --store ./my-sidecar --session ./my-contact-session.json
python3 ref.py import --store ./my-sidecar --file ./original-export.csv --mapping ./my-numeric-mapping.json
python3 ref.py session-event --store ./my-sidecar --session-id contact-fin-1 --type probe_loose --measured-at '仪表实际时钟或相对秒' --note '实际情况；时间不明则省略measured-at'
python3 ref.py compare --store ./my-sidecar --trajectory ./same-run-frozen-trajectory.jsonl --output ./comparison-NEW
```

事件命令中的时刻是待替换说明，不是实测；不确定度另用`--uncertainty-s`，未知保持空。原CSV按SHA原字节归档，原行号/值及拒绝原因保留；规范化写新sidecar。相邻等温不去重，空值/ERR不补零，时间不明不配对。只能对同run冻结轨迹独立比较，不拿旧M冒充新run。外部温度不进入重训、状态纠偏或控制；零测温也有报告。

**备用功能保留：** `mark`/`record --revise`支持人工迟录和原图关联，`watch-events --replay`支持旧事件的稀疏提醒回放；完整用法见README。连续模式不启动这些逐点提醒。本轮到交回复审停止，不部署、不实测。
