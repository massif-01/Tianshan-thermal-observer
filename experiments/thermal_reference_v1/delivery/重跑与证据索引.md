# 证据与独立重跑

压缩包顶层为thermal_reference_v1。该目录保留原交接文件、冻结规范和模型、软件、最小旧M适配输入、明确合成的人工/连续输入、结果、公开文档发布证据及报告；没有新现场测温。

先用Python标准库运行`python3 verify_archive.py 证据包.zip --extract 一个不存在的新目录`，检查CRC与所有成员SHA。进入解压的thermal_reference_v1，运行：

```sh
python3 ref.py plan
python3 run_offline.py --output /private/tmp/tto-reference-replay-NEW
```

已有Python3.10+和pytest即可检查，绘图另需已有本地Matplotlib与中文字体。本机默认入口会选择已经存在的本地pytest解释器，不安装依赖、不联网、不调用TTO生产入口或任何publication脚本。无Matplotlib时图的状态明确不可用，JSON/MD/HTML仍可用。来源最小副本随包附带，不依赖旧研究大ZIP；`prepare_sources.py`仅用于原目录有旧原件时重新准备，不是重跑的前置。
