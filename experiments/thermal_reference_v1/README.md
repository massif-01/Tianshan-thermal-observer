# TTO-REF-PREP-v1.0：局部表面参照工具（本地候选）

本目录实际实现连续CSV/JSON导入、人工打点/迟录修订、原图关联、确定性提醒、独立时钟对齐及冻结轨迹对照。ADD1将已购买的YET-610L+K型探头、耐温聚酰亚胺胶带固定的局部表面连续记录作为主路径。通用软件已完成，真实CSV映射待1～2分钟样例，现场测温未执行；物理对应未验证。软件只交本地patch，未随文档PR发布。

现在可安全重跑离线演示，不运行负载或设备入口：

```sh
python3 ref.py plan
python3 run_offline.py --output /private/tmp/tto-reference-demo-NEW
```

在本目录运行；输出目录必须是新目录。一条入口使用本机已有pytest/Matplotlib运行时，不安装依赖或联网；在其他机器用已有Python 3.10+、pytest运行，图形另需本地Matplotlib与中文字体。核心CLI仅用Python标准库。没有Matplotlib时JSON/Markdown/HTML仍生成，图形状态明确为不可用，不伪称已画图。本轮本机已生成并目视检查图。

`run_offline.py`真实调用CLI完成：计划→不可变会话→14条虚拟提醒及旧M事件回放→无数值打点→迟录追加修订→CSV/JSON与重复导入→合成对照→零外部点报告→双通道连续CSV/重复导入/探头事件与独立对照→针对性测试→SHA回读。它不运行历史模型搜索，也不把合成读数叫实测。最小真实输入已随证据提供，重跑无需旧大ZIP；可选的旧研究目标断言检查在原研究目录可用时执行，原件不改写。

## 单一CLI

| 命令 | 实际行为 |
|---|---|
| `plan` | 默认离线打印测点限制与固定计划，不决定新负载 |
| `init-session` | 登记不可变run/site/kind/统计量/几何/仪器设置/钟域/一个参考ID；设置变化另开会话 |
| `watch-events` | 只读指定现有本地events.jsonl；默认一次启动扫描，`--replay`虚拟回放，`--follow`仅供未来获准后的本地追加读取 |
| `mark` | 记本地主机按键UTC/monotonic，可空数值/图片；默认不是曝光时间 |
| `record --revise` | 迟录/更正追加revision及supersedes，原条目不覆盖；原按键时间保留 |
| `record --capture-interval` | 交互开始至输入完成的本地主机区间；时钟不明不硬配到相机/run，非精确曝光 |
| `import` | 默认numeric_export路径；时间/温度/单位/通道→测点显式映射，保存原CSV/SHA/行号/原值与异常台账；同文件SHA+映射不重复计数，相邻等温行保留 |
| `session-event` | 开始/结束/校时、探头移动/重贴/松脱各自记时；探头事件之后原会话不静默恢复对照 |
| `adapt-trajectories` | 只复制已封存的主G2、QS/LP30/LP120、原Tf与需求；读取旧资格台账，不重估状态/参数 |
| `compare` | 合法as-of、完整时间区间范围；一次预登记背景增量；输出中文JSON/Markdown/HTML/图表 |

实际参数见`python3 ref.py <命令> --help`，可复制命令见[一页操作卡](一页操作卡.md)。没有生产`tto mark`命令，没有相机SDK、RTSP、云或新服务。主路径由仪表独立连续记录，结束后一次导入，不需要十几次人工抄读。人工/红外/固定提醒代码保留备用。

## ADD1连续CSV默认路径

先复制`templates/contact-session.example.json`登记surface_contact、YET-610L/K型探头、同一固定位置、聚酰亚胺胶带及实际表面情况。仪器已买并确认可导出CSV；实际格式、精度、接触、探头响应仍未验证。接触式不要求IR发射率/反射/ROI，无安装照片也可完成软件。移动/重贴/松脱须追加事件并使用新会话，原会话后续原值保留，但不再当有效同位置参照。

`templates/numeric-export-mapping.example.json`列名全是待替换占位符，不是YET格式推测。支持CSV编码/分隔符，时间、温度、C/F、通道列或常量；长表用channels显式路由到session/site，宽表选一个温度列并固定通道，逐通道导入。JSON同样使用显式映射。

时间轴支持`timestamp`、`relative_seconds`、`sample_index`。后两种必须有第0秒的独立开始锚点、正的sample_interval_s及interval_basis；序号还必须声明index_origin。不从原行号生成缺失采样时刻，不使用mtime/导入时刻。首末独立锚点支持漂移核对，未知误差不填0。计划1秒保存，导入回执核对原CSV实际间隔/同时间/倒序/等温对，不能把采样周期称探头响应。

原表保存在`imports/raw/<SHA>.<扩展名>`，映射另存，逐行台账保存CSV物理行范围、逻辑行号、原值、原采样时刻及拒绝原因，规范化输出在新store。空温度保留null，ERR/NaN等拒绝并说明原因，不补0、不插值、不按温度去重。相同原文件SHA+映射可幂等；变化值更正仍需明确revision。导出时间仅在有原始依据时填写，与采样/开始锚点/导入UTC分开。

26项本地测试及20个CLI/检查调用通过。连续合成CSV240行、2通道，239条规范化记录（238个数值、1个空值），1行ERR进入拒绝台账；两通道均检测到缺失索引造成的2秒间隔，等温新行保留。所有外部值明确标合成，未宣称真实YET格式验收。软件无USB、串口、厂商上位机驱动或第二采集器。

## 数据与时间合同

`sessions/`固定run、局部测点、表面类型、统计量、几何/设置、时钟证据与`reference_record_id`。未知仪器、发射率/反射/ROI/精度保持null，不默认裸金属0.95。鳍片局部红外、背板、接触探头、空气探头、用户环境备注分别命名；红外对着鳍片不是测空气。24°C只属于旧M，不复制给新run。

`records.jsonl`按实际写入时间追加，不回填成现场实时输入。`prompt_due_at_utc`/`prompt_emitted_at_utc`、`operator_mark_at_utc`、`measured_at_raw`或`measured_interval_raw`、`recorded_at_utc`分开。原时区、钟域、时间来源和未知不确定度都保留。UTC映射只在派生对照中，不回写原记录。mtime仅诊断；图像元数据时间原文单列，不自动当曝光。不OCR、不按伪彩颜色制造温度，也不声称已解未知辐射格式。

允许带时区ISO时间、显式声明时区的本地时间、已声明钟域的数值秒。无时区且无锚点时不默认主机本地/UTC；数字表示秒，不猜相机毫秒单位。1个独立锚点只支持偏移并标漂移未验证；>=2个用首末独立锚点估计时钟比例并保留残差，锚点外不假定已知误差；未知时间误差不填0、不报精确配对。没有任何温度相关性寻优错时。

`artifacts/`用内容SHA存原字节。CSV导入显式映射见`templates/import-mapping.example.json`；没有数字可只留原图。改值/时间用`record --revise`或批量行提供最新`supersedes`，不会覆盖旧记录。

## 轨迹与资格

`fixtures/real/`是旧M的已冻结状态/观测最小适配及原事件字段子集；不是新实测或表面温度。`fixtures/synthetic/`所有外部温度与图片/任务事件均是合成演示。三套model.json原字节另在`frozen/models/`，本轮只使用固定主模型已有输出，无重训练。

外部读数不进入G2/Ts/LP或需求生成。快通道的实测TJ独立保留，不因模型缺资格一并丢掉；Tf A-long仍是TJ估计，因果Tf锚定不算预测。G2/LP30主对照，QS/LP120辅助，LP依赖同一G2的QS。

as-of的合法持有区间直接引用旧封存fast-status资格台账：只有真正到达的新输入维持原资格，原始快照有效截止和每个资格来源引用均保留，没有另写质量解析器或延长旧TTL。外部时刻只取合法过去快照，记录滞后；时间区间须全段有资格且同一严格段，不跨缺口/源边界、不插值，也不在区间挑最接近温度的点。模型和真实TJ断线各按自身原资格保留。

每run/测点/会话只用一个预登记背景ID，可能是热背景，不叫冷机。若该点没采到/时间不明则不自动改用另一个，增量比较不可用，绝对材料仍保留。局部表面和潜在Ts未标定，不计算“Ts准确率”、热容或风扇收益；稀疏点也不证明完整峰值和秒级时滞。未知仪表误差不能用来支持0.004°C差别的排名。

## 确定性提醒（人工/红外备用，连续模式不逐点提醒）

模板稀疏计划：背景开始+30/+120秒；稀疏组+180秒和实际结束+30/+120；连续组前点由已发生的前置待机开始+270秒生成，连续开始+60及实际结束+30/+120/+300。可选中等块同样用预先绑定的前置待机计时采组前点，再用实际结束+30/+120/+300。若缺少可靠前置事件/计划，不从未来开始时刻倒推“组前”。实际绑定待现场前确认，模板不是新试验授权。

最多14条主提醒，间隔至少30秒，重叠合并保留所有checkpoint ID/原到期时刻；晚到/重复/旧日志启动不追赶。回放把模拟发出时刻另列，真实发出时间仍null。漏测不重排、不延长、不补跑；停止本工具只停止提醒，不控制负载。
