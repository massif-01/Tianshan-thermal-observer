**本清单检查研究是否真的完成、结论是否可比较，不要求某个模型必须获胜。**

## 一、三步验收

| 项目 | 验收要求 |
|---|---|
| M归档 | 真实run/内层索引、2504新TJ及工作块边界有原ref；31秒等未误写成强制20秒任务；准入覆盖与原质量分开。 |
| 24°C | M专属sidecar存在；来源为用户；L/S未补；旧null/原SHA不变。 |
| 数据与计划冻结 | 拟合前固定数据角色、评价规则、旧模型及第三步矩阵；时间域、来源、软件版本可查。 |
| 旧模型检验 | 九份指定模型JSON加载正确，无任何旧θ/缩放/P10更新；三套均对M有实际输出，LS为主。 |
| 阶段顺序 | stage2封存先于首次stage3拟合；原报告与旧成绩保留。 |
| 新拟合 | D-LM/D-SM/D-LSM实际完成G1/G2与紧凑Ridge；训练与目标不混；未执行/失败有原因。 |
| 24°C诊断 | D-LSM-G2-A24实际尝试；M的E固定24，只有该项改变；六次以内，训练目标选初值。 |
| 初态 | M长连续段贯穿各块，非每块重置；因果前缀比较与用全段拟合初态的重建分别列。 |
| A/B | A-long无未来TJ反馈；A-roll未来输入权限单列；B没有未来输入/真实结束；HOLD/RELAX均保留。 |
| 公平比较 | 同rule/同初始化预算/同起点同标签；正常/辅助缺口/异常分层；45/90资格不捆绑。 |
| 结果完整 | 待机、短峰、持续负载、回落、尾部、覆盖、参数贴边与环境边界皆报告；不只全局MAE。 |
| 原件保护 | 原始数据、模型/旧spec/test-used不覆盖；本地新代码与patch准确。 |
| 停止边界 | 无设备连接/部署/风扇写入/在线学习/提交推送；模型deployable=false。 |
