## 使用

先读`01-三步实施方案.md`，再使用`02-给Codex的指令.txt`和`templates/experiment-spec.json`。`03-验收与回执.md`给出交回标准。本包自包含需要的L/S/M原归档、首轮研究和新评价代码参考；不需要再找旧附件，也不要使用之前被截断的短问答ZIP。

可先运行唯一已提供的校验命令（标准库，无网络，不解包或运行候选代码）：

```sh
python3 scripts/verify_handoff.py
```

模型研究入口由Codex在隔离研究目录新增，当前没有声称`tto`已支持某个新参数。本包是执行交接，不是新训练模型、固件或安装候选。
