# TTO 主线回归：冻结模型小批试跑与生成／校准

**合同：TTO-MAINLINE-RETURN-v1.0｜2026-10-21｜本轮交付是可执行的研发计划，不是已实现软件或现场授权。**

## 先读这一页

**产品决定：CPU逐核先导支线暂停。先把已有G2成果变成可持续只读运行的版本，在小批机器上观察；模型生成与校准同时开发。** 不再以CPU 60秒／12请求、jtop录像、毫秒领先、外部探头或Web UI完成为主线前提。

**工程决定：复用已接受的原生采集、I-02、冻结G2、估计器、单线程运行规则和安装身份；拆开采集、数据质量、模型输出、实验执行、真实控制的资格。** 本阶段不改天山OS风扇控制，不向设备写PWM。观察失败不能自动结束用户已有业务。

## 阅读顺序

共同读 `00-决策冻结与旧任务替代.md`、`01-产品与工程总体方案.md`、`05-接口与评价合同.md`、`06-集成验收与试跑计划.md`，再读自己的专项文件。

## 当前授权

可以本地读代码、使用已授权历史数据、开发、有限离线生成新模型候选（不覆盖冻结模型）、自建服务测试、打包、准备文档及本地Roadmap增量。

**现在不连接设备、不部署、不启动推理、不调风扇/功耗/生产采样/TTL、不推送、不创建PR、不写GitHub。** 完成第一份可试跑观察版本后汇总复审；实际设备清单及运行窗口由用户一次性批准。本包支持将来一个已批准窗口内从安装直接进入观察，不要求每完成一个小步骤再返回等待。

## 完成标准

不是“所有未来想法都已解决”，而是：
1. 当前G2完整封存且在稳定只读软件中可运行；无CPU侧支线也能记录、估计、发布条件预测、归档。
2. 能按指定设备清单进行有界的小批观察，现场故障分层显示；默认不主动发负载。
3. 已有辨识能力成为可重复的生成／校准／比较工具，候选可以被接受、拒绝或标为证据不足，原版始终可回退。

本包没有重新执行旧实验或证明新的模型／噪声收益。原始大数据不递归复制，准确入口和哈希见来源文件；已有三个对话应复用本地对应原件。
