## 不变的目标与数学含义

同一工具面向不同模组、热源、材料、几何、热容和风量组合，生成/评价/校准设备专属模型。低阶灰箱优先、Ridge与简单基线保留，模型结构在有证据时可变化；无需一开始搭全面自动结构搜索。

当前G2等效方程仍是：

```text
dTf/dt = -a*(Tf-Ts) + b_g*P_GPU + b_c*P_CPU_SOC_MSS
dTs/dt = c*(Tf-Ts) - (d0+d1*u)*(Ts-E_run)
y_hat = Tf, u = successful_PWM/100
```

θ={a,c,d0,d1,b_g,b_c}是动态参数；E_run是等效边界；Tf对TJ输出负责；Ts未被直接测到。旧M确认室温24°C和A24诊断不改写，也不移用到新run。两rail分别有语义，CPU/SOC/MSS不是纯CPU；共线不否定组合预测，也不证明独立热源贡献。潜在温度不等于整块铝均温，温度面积不是焦耳。

## 验证规则

- A-long/A-roll允许规定范围的实际未来输入、不读未来TJ反馈；B只使用预测时已到达信息。15/45/90秒各自判标签。同起点/标签/信息截止比较，覆盖单列。
- 模型当前Tf锚定TJ的零误差不是预测收益。M未遮挡慢态只是参考估计；物理Ts误差须另有真值。合成mask与已知状态模拟有不同用途，不冒充真机。
- 原60秒连续条件保留作历史基线，新估计器单独版本化；不改TTL/raw_valid/异常事实来造模型覆盖。冷启动与运行中缺口都验证。
- 固定θ状态更新、E边界估计、动态θ自学习、候选启用、控制权限分别登记。在线参数研究遵守先预测、真值到达后评分、再更新。
- 局部YET先作独立观察，不进入本轮状态纠偏/重训。记录位置、接触与仪表响应/时钟不确定性，不按相关性最佳平移；单点不等于全结构均温。
- 成功PWM不是RPM；风扇输出增加与局部表面下降相容，但现有闭环数据不单独证明因果或低PWM安全。用户1060铝/约2mm作为设计事实；未验证的“铜比铝三倍”不成为公式中的材料常数。
