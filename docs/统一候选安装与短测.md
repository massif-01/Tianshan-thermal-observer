# observe.7 + Web rc9 统一候选

同一安装包包含两个独立 Python 环境的离线材料：observe 是唯一采集/模型/预测账本来源，Web 只跟随显示。后端版本 `0.2.4+observe.7`，Web `1.0.0rc9`；冻结模型不变，软件身份已经改变。

本地构建（Python 3.12 已有 build/setuptools/wheel，frontend 已完成 npm ci）：

```sh
python tools/build_unified_candidate.py --output /private/tmp/tto-unified-rc9
```

输出必须全新。构建前端并重算源文件身份，检查 wheel 实际内容；复用已锁定依赖，不覆盖历史候选、wheel 或旧安装。外层 SHA256.json 覆盖全部安装材料，build-receipt.json 的 Git HEAD 是构建起点，最终字节身份以清单为准。

N305 安装须先确认旧测试归档、当前无冲突观察进程，并取得该次安装/短测授权。使用 Linux x86_64 CPython 3.10，新绝对 prefix；例如在解压目录：

```sh
python3.10 install.py --prefix /home/rm01/TTO-unified-rc9-NEW \
  --active-descriptor /home/rm01/TTO-unified-rc9-NEW/session/active.json \
  --service none --access local
```

安装不创建/启用服务，不启动采集或 Web，保留旧 prefix。backend/ 是后端 venv，web/ 内有单独 Web venv；不可混装同名 tto/tto_field。Web 配置固定 follow、本机 127.0.0.1:59009；访问使用已授权 SSH 转发，不扩大 LAN 暴露。

短测应使用本次新许可、注册与输出目录，带 `--publication-descriptor` 运行唯一 observe。不开推理负载、不写风扇、不接管旧服务。启动 Web 后核对状态与预测 ID/值/目标/评分是否与本次账本一致；检查 Web 断开/重启后恢复、采集仍在继续、终态评分及撤回。进程只停止本次创建者，记录日志与实际运行身份。

回退：停止本次手动启动的 Web/observe，保留新记录和安装。旧软件目录及旧测试原件完整保留，旧服务是否恢复须按该次授权执行，不自动切换。

结束契约：实时身份始终来自最后一帧（停机边界也不改写）。正常终态单独给出最后一组正式预测的 `history_identity`，Web 用它查询保留窗口内的历史和评分；并非跨来源混算，也不是整场永久历史数据库。最终快照先写成功，再发布 ended；生成、写入或成功登记失败时发布 `publication_failed`，页面明确显示“发布失败 · 最终结果未确认”，不宣称结果完整。若整个目录已无法写入，失败登记也可能失败，此时日志记录错误、流关闭并撤回实时值；无法保证持久化故障通知。原始预测账本仍是归档依据。
